# PureLeaf – Natural Skincare Landing Page

## Project Overview
PureLeaf is a landing page design for a natural skincare brand that promotes plant-based skincare products and sustainable beauty.

## Design Sections
- Navigation Bar
- Hero Section
- Why Choose PureLeaf?
- Best Sellers
- Footer

## Features
- Clean and nature-inspired design
- Green and cream color palette
- Product showcase
- Eco-friendly brand identity
- Simple navigation

## Tools Used
- Figma
- UI/UX Design
